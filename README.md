这是什么
Linkverse-unland 是一个纯静态的个人网址管理页面。

它不像在线书签服务那样需要账号和同步，也不会把你的浏览习惯上传到服务器。整个应用只有一个前端页面：打开 index.html 就能使用，收藏保存在当前浏览器本地。

适合这些场景：

想把常用网站、工具、文档和灵感链接放在一个安静的页面里
不想注册账号，也不想依赖某个书签服务
喜欢深色、玻璃质感、有一点个人气息的界面
需要分组、搜索、拖拽、待办和本地音乐这些顺手的小工具

数据与隐私
收藏保存在浏览器的 localStorage 中，键名为 linkverse.library.v1。

不会上传到任何服务器
不会写进项目文件夹
关闭网页、关闭浏览器后仍然保留
清除浏览器网站数据、使用无痕模式或更换浏览器，可能导致收藏不可见
file:// 和 http:// 属于不同存储位置，建议固定一种打开方式
需要迁移或备份时，请使用页面右上角的「导出」，会生成 JSON 文件。

待办保存在 linkverse.todos.v1，音乐设置保存在 linkverse.music.v1。目前「导出」只备份网址收藏，不包含待办。

已知限制
拖拽排序依赖鼠标操作，触屏设备暂不支持；移动端可通过「编辑收藏」修改页面和分组。
手动选择的音乐文件夹只在当前标签页内有效，关闭页面后需要重新选择。
favicon 需要联网获取；离线或网站禁止外链时会回退到文字图标。
待办不包含在网址收藏的导出备份中。
这是一个纯前端本地项目，不提供账号、云同步和多设备自动同步。
